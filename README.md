# 文登蓝投“一码呼” V0.1 可交互演示原型

面向甲方领导汇报的静态高保真交互原型，围绕同一条居民诉求工单串联四类角色：

1. 居民小程序：居民首页、我要报修、工单进度/评价
2. 物业工单中心：工单中心、工单详情、受理派单
3. 物业/网格工作人员小程序：我的任务、现场处理
4. 集团监管端：集团驾驶舱、工单全过程穿透监管

## 演示主线

居民发现“蓝海嘉园 3号楼2单元一楼公共区域漏水” → 扫码上报 → 物业受理 → 派给工程维修人员王海 → 工作人员接单并到场处理 → 上传完成结果 → 居民确认评价 → 集团端查看全过程。

所有端共享同一工单 `LT202609030018`，状态保存在浏览器 localStorage 中，可通过右上角“重置演示”恢复初始状态。

## 视觉基线

参考政务类小程序的现代简洁风格：政务蓝 `#1779FF`、深蓝灰 `#192338`、白底卡片、大圆角、轻阴影、低密度文本。PC端沿用同一套视觉语言和配色。

## 使用方式

直接打开 `index.html` 即可演示。建议在 GitHub Pages 或任意静态 Web 服务中部署。

推荐演示顺序：居民端 → 工单中心 → 工作人员端 → 居民确认 → 集团监管。
